六、关键设计要点

🔄 三级降级策略

级别说明
一级LCEL 链 → LLM + 知识库检索生成报告
二级模板生成 → 纯 f-string 拼接，不依赖 LLM
三级基本错误信息 → 仅返回患者ID和结节数量

📎 reasoning 审计参数

每个工具函数都有一个 reasoning 参数，由 LLM 自动填充思维链过程。

不参与业务逻辑，仅用于：

  • 审计日志记录
  • AgentLoggingHandler 回调输出
  • 医疗决策可追溯

🏷️ thread_id 统一标识

同一个 thread_id 贯穿三个子系统：

组件作用
MemorySaver对话历史分片 key
CaseContext病例上下文缓存 key
AuditLogger审计日志文件名标识

📦 字段归一化

_normalize_detection_result() 兼容 LLM 可能产生的不同 JSON key 命名习惯：

diameter_mm → diameter
confidence → score
location_x → center.x
...
