## 短期规划（1-3个月）

### Agent 能力增强

- [ ] **多病例管理 — 支持同时管理多个病例，支持对比分析
- [ ] **上下文字段扩展 — 增加既往病史、症状描述、实验室检查等字段
- [ ] **动态上下文注入 — 根据用户输入动态决定注入哪些信息
- [ ] **Agent 自我评价 — Agent 能主动询问缺失信息

### 视觉能力增强

- [ ] **结节分割 — 在检测基础上增加分割能力，测量体积和三维重建
- [ ] **DICOM 支持 — 支持 DICOM 格式，读取元数据
- [ ] **多平面重建 — MPR 多平面重建显示

---

## 中期规划（3-6个月）

### 多模态融合

- [ ] **报告理解 — 支持输入病理报告、检验报告等文本
- [ ] **多模态 Agent — 融合影像 + 文本 + 结构化数据联合推理

### 多 Agent 协作

- [ ] **检测 Agent — 专注影像分析
- [ ] **诊断 Agent — 专注知识推理与诊断
- [ ] **报告 Agent — 专注报告撰写与排版
- [ ] **协调 Agent — 负责任务分配与结果整合

### 知识库增强

- [ ] **知识图谱 — 从纯向量检索升级为知识图谱增强检索
- [ ] **多源知识 — 接入更多医学指南、论文
- [ ] **知识更新 — 支持增量导入

---

## 长期规划（6-12个月）

### 工程优化

- [ ] **Web UI — 前端可视化交互界面
- [ ] **批量处理 — 支持队列批量分析
- [ ] **分布式推理 — 支持多GPU分布式推理加速
- [ ] **模型量化 — 模型轻量化，降低资源占用

### 模型优化

- [ ] **微调模型 — 在医学数据集上微调 LLM
- [ ] **检测模型优化 — 针对特定场景优化检测精度
- [ ] **嵌入模型微调 — 医学领域专用嵌入模型

### 安全与合规

- [ ] **数据脱敏 — 患者信息脱敏处理
- [ ] **可解释性 — 诊断结论的可解释性增强
- [ ] **合规性 — 符合医疗AI相关法规
